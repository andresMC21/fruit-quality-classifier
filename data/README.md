# Datos
- `raw/kaggle/`: dataset de referencia (no se versiona; ver README raíz para el enlace).
- `raw/mixed_quality/`: fotos con varias frutas; se segmentan en `interim/segmented/`.
- `raw/own_images/`: imágenes propias (mín. 30-50), fondo uniforme, distintas madurez/tamaño/defectos.
- `annotations/annotations.csv`: una fila por imagen. Es lo único que se comparte entre grupos.
- `processed/`: tensores/características y splits fijos (train/val/test).
