# Instalación
1. Python 3.11 y un entorno virtual: `python -m venv .venv` y luego `.venv\Scripts\activate` (Windows).
2. `pip install -r requirements.txt` (o `conda env create -f environment.yml`).
3. Descargar el dataset de Kaggle y descomprimirlo en `data/raw/kaggle/`; la carpeta de calidad mixta va en `data/raw/mixed_quality/`.
4. Descargar las imágenes propias y las de otros grupos desde la carpeta compartida (enlace en `data/README.md`).
5. Ejecutar los comandos del README desde la raíz del repositorio.
