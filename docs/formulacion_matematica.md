# Formulación y fundamentos matemáticos (PI3)
1. **Formulación del problema:** variables (imagen x, calidad y, tamaño s), por qué es complejo, modelo formal (p. ej. f: X -> {1..K} x {S,M,L}).
2. **Estrategia de solución:** justificación del modelo; alternativas descartadas y por qué.
3. **Fundamentos aplicados:** normalización, distancia/kernel (SVM), función de pérdida (entropía cruzada), métricas (F1 macro), regularización, validación cruzada.
4. **Análisis de resultados:** interpretación matemática (error, generalización, sobreajuste).
5. **Conclusiones técnicas:** conexión teoría <-> solución; mejoras.
