| Título, resumen, introducción | 0,6 | Contexto y justificación |
| Fundamentos teóricos | 0,7 | Solo lo que se usa (Otsu, SVM, CNN, F1) |

| Resultados | 1,2 | Tabla comparativa, matriz de confusión, curvas |
| Análisis de resultados | 1,0 | Generalización, sobreajuste, errores, comparación con la literatura (6) |
| Ética e impactos | 1,0 | Tabla PI1 y matriz PI2, compactas (1, 2) |
| Conclusiones y trabajo futuro | 0,4 | (7) |
| Referencias | 0,6 | IEEE |

Lo que no quepa (tablas completas de experimentos, guía de anotación) va al repositorio y se referencia.
